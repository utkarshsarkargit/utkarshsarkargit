## 📌 Featured projects

### 🔗 [URL Shortener](https://github.com/utkarshsarkargit/url-shortener)
A full-stack URL shortener built with **FastAPI**, **SQLAlchemy** and **PostgreSQL** (Dockerized locally), deployed live on **Render** + **Neon**.
Secrets are kept out of the repo via `.env`, and the redirect logic handles messy user input.
🚧 *Coming next: QR codes per link, click tracking and a redesigned frontend.*

### 🛡️ AI Privacy Agent *(in progress)*
A local tool that uses AI/ML to detect personal and sensitive information (including API keys and credentials) in files, then redacts it before the file is uploaded to a cloud LLM.
Features: per-document risk scoring, manual-review flags for uncertain detections, and reversible tokenization-based redaction.
